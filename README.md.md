# InterviewAce AI

## Overview

InterviewAce AI is an Agentic AI-based Interview Trainer developed for the IBM SkillsBuild AICTE University Engagement Program.

The system helps students prepare for technical and HR interviews by generating role-specific questions and providing interview guidance.

## Features

* Technical Interview Questions
* HR Interview Questions
* Multi-Agent Architecture
* Personalized Interview Preparation
* Feedback Suggestions

## Technologies Used

* IBM Granite Models
* LangFlow
* Python
* RAG Architecture

## Agents

1. Resume Analysis Agent
2. Technical Question Agent
3. HR Interview Agent
4. Feedback Agent

## Future Scope

* Resume PDF Analysis
* Voice Interviews
* AI Feedback
* Company-Specific Mock Interviews
